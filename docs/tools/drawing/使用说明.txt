灵感画室 · PIGMENT STUDIO

打开
双击上一级目录中的“灵感画室.html”，使用 Chrome 或 Edge 打开。
这是独立离线网页，不需要联网、安装或登录，可以单独复制使用。
本文件夹中的 index.html 是开发版入口，需要保留相邻 CSS 和 JS 文件。

工具（20 种）
绘画：画笔、铅笔、马克笔、荧光笔、喷枪、橡皮擦。
颜色：吸色器、油漆桶、渐变。
形状：直线、箭头、矩形、圆形、正多边形。
编辑：文字、矩形选区、移动、裁剪。
视图：抓手、缩放。

使用要点
- 右侧调节笔刷大小、硬度、不透明度和颜色。硬度越低，边缘越柔。
- 支持左右/上下对称绘画，辅助网格不计入导出图片。
- 油漆桶默认采样全部可见图层，但将颜色画在当前图层。
- 渐变从当前颜色过渡到“渐变尾色”，可选择线性或径向。
- 形状可分别开关描边/填充；按 Shift 约束圆形、方形和直线方向。
- 选区会限制绘画、填色、擦除范围。按 Esc 或 Ctrl+D 取消。
- 移动工具：有选区时移动选区内像素；没有选区时移动整个当前图层。
- 裁剪工具：拖出区域后，按 Enter 或“应用裁剪”。裁剪对全部图层生效，可撤销。
- 文字会栅格化绘制到当前图层，可先新建图层方便独立移动。
- 图层支持新增、复制、重命名、排序、显隐、锁定、不透明度调整和删除。
- 默认背景图层已锁定，点击锁图标解锁后才能修改；隐藏背景可导出透明 PNG。
- 最多 12 个图层；画布单边最大 4096 像素，总像素不超过 800 万。
- 撤销最多保留 25 步；复杂作品会按内存预算减少较早的记录。

快捷键
B 画笔，P 铅笔，E 橡皮，I 吸色，G 油漆桶，L 直线，R 矩形。
M 选区，V 移动，T 文字，C 裁剪，H 抓手，Z 缩放。
[ 和 ] 改变笔刷大小，X 交换颜色。
滚轮缩放，Shift+滚轮横向平移，按住空格拖动，0 适合窗口。
Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
Ctrl+S 保存工程，Ctrl+Shift+S 导出 PNG，Ctrl+O 打开文件。
? 打开操作指南，可从指南中加载一个可编辑示例。

保存与恢复
- 自动暂存保存在本机当前浏览器中，不跨浏览器、设备或文件位置同步。
- 浏览器存储空间不足时会显示“请保存作品”，仍可手动保存。
- “保存作品”下载 .pigment.json 工程，包含图层及画布信息。
- “打开”可恢复工程，也可将 PNG/JPEG/WebP/GIF 图片导入为新图层。
- “导出 PNG”按画布原始像素尺寸合并可见图层，保持隐藏背景后的透明度。
- 临时选区、撤销历史、笔刷偏好不写入工程；工程保存图层像素和属性。
- 数位笔压感需要设备和浏览器支持；鼠标无需压感也可正常绘画。
