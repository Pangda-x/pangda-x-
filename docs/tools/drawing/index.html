绘画与颜色

画笔、铅笔、马克笔、荧光笔和喷枪拥有不同笔触。硬度越低，笔触边缘越柔和。油漆桶默认采样所有可见图层，在当前图层填色。

形状与编辑

拖动绘制形状，按住 Shift 约束比例。选区限制绘画范围；移动工具移动选中区域或整个图层。裁剪后按 Enter 应用。
